# OCR Models

PP-OCRv6 tiny ONNX detection and recognition models from PaddlePaddle/PaddleOCR
(Apache-2.0). Vendored unchanged so clients do not depend on a third-party model
host during identity validation. Photos remain on the client device.

Official model information:
https://github.com/PaddlePaddle/PaddleOCR/blob/main/docs/version3.x/algorithm/PP-OCRv6/PP-OCRv6.en.md

Source base URL:
https://paddle-model-ecology.bj.bcebos.com/paddlex/official_inference_model/paddle3.0.0/
